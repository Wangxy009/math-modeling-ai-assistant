# 论文正文模板

## 摘要

用 300-500 字说明：研究对象、主要方法、关键结果数字、最终结论。摘要不要只写流程，要写结果。

## 1. 问题重述

用自己的话重述题目背景和待解决问题，明确每一问的输入、输出和评价标准。

## 2. 问题分析

说明每一问的建模难点、变量关系、数据可用性、可能的模型路线和选择理由。

## 3. 模型假设

| 编号 | 假设 | 理由 | 可能影响 |
|---|---|---|---|
| H1 |  |  |  |

## 4. 符号说明

| 符号 | 含义 | 单位 |
|---|---|---|
|  |  |  |

## 5. 数据处理

说明数据来源、缺失值处理、异常值处理、变量构造和标准化方法。

## 6. 模型建立

写清目标函数、约束条件、关键公式、参数含义和模型适用范围。

## 7. 模型求解

说明算法流程、求解工具、参数设置和计算复杂度。必要时放流程图或伪代码。

## 8. 结果与分析

用表格和图说明结果。每张图表后都要有一句解释：它证明了什么。

## 9. 模型检验与敏感性分析

至少做一种：误差分析、交叉验证、灵敏度分析、稳定性检验、对比模型。

## 10. 优缺点与改进

优点要具体，缺点要诚实，改进要可执行。

## 参考文献

使用统一格式，避免 AI 编造文献。所有文献都要能查到。
