# 国赛论文审稿清单

## 摘要

- [ ] 是否说明了每一问使用的方法？
- [ ] 是否给出关键结果数字，而不是只有空泛结论？
- [ ] 是否写出了模型优点或实际意义？
- [ ] 是否避免出现“本文首先、然后、最后”的流水账？

## 问题分析

- [ ] 是否逐问分析，而不是直接套模型？
- [ ] 是否说明为什么选择该模型？
- [ ] 是否识别题目中的隐含约束和评价标准？

## 模型假设

- [ ] 假设是否必要？
- [ ] 假设是否能简化问题但不明显扭曲现实？
- [ ] 是否避免了“数据真实可靠”等无效假设？

## 数据与代码

- [ ] 原始数据和处理后数据是否分开保存？
- [ ] 缺失值、异常值和单位换算是否说明？
- [ ] 结果是否能由代码复现？
- [ ] 图表中的数字是否和代码输出一致？

## 模型与结果

- [ ] 目标函数和约束条件是否完整？
- [ ] 参数含义是否明确？
- [ ] 是否有模型检验、误差分析或敏感性分析？
- [ ] 结论是否没有超出模型支持范围？

## 图表

- [ ] 每张图是否有编号和标题？
- [ ] 坐标轴、单位、图例是否完整？
- [ ] 图表是否直接服务某个结论？

## 合规

- [ ] 是否保留 AI 使用记录？
- [ ] 是否准备 AI 工具使用声明？
- [ ] 是否说明 AI 输出经过人工核验？
- [ ] 是否检查参考文献真实性？
