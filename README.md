# Math Modeling AI Assistant v0.1

这是一个面向全国大学生数学建模竞赛的 AI 辅助工作区。它的目标不是让 AI 代替队伍完成核心建模，而是把审题、方案比较、代码实验、论文写作、合规记录和复盘组织成一套可迭代流程。

## 核心原则

- 队伍自己决定核心模型、关键假设、结果解释和最终论文。
- AI 用于辅助：拆题、查错、代码调试、表达优化、审稿质检、记录整理。
- 所有 AI 输出必须经过人工核验，尤其是公式、代码、数据来源、结论数字和参考文献。
- 比赛期间保留 AI 使用记录，最后整理为 AI 工具使用声明和详情文件。

## 目录说明

| 目录 | 用途 |
|---|---|
| `00_inbox/` | 临时放赛题、通知、附件、截图、参考资料 |
| `01_problems/` | 每道题的独立项目目录 |
| `02_data/` | 原始数据和清洗后数据 |
| `03_code/` | 通用代码骨架和实验脚本 |
| `04_outputs/` | 图表、结果表、模型输出 |
| `05_paper/` | 论文草稿、摘要、最终稿 |
| `06_ai_records/` | AI 使用日志、合规声明、提示词记录 |
| `07_review/` | 审稿清单、问题清单、修改记录 |
| `08_knowledge/` | prompt 库、模型卡、常用方法笔记 |
| `09_retro/` | 每次训练题或比赛后的复盘 |
| `scripts/` | 自动创建新题目工作区等辅助脚本 |

## 第一次使用

1. 把赛题 PDF、附件数据放到 `00_inbox/`。
2. 运行 `scripts/init_problem.py` 创建新题目工作区。
3. 按 `08_knowledge/prompts/01_problem_analysis.md` 做第一轮审题。
4. 把 AI 使用过程写入 `06_ai_records/ai_usage_log.csv`。
5. 用 `03_code/main.py` 作为实验入口，所有结果导出到 `04_outputs/`。
6. 用 `05_paper/paper_outline.md` 写论文骨架。
7. 提交前用 `07_review/reviewer_checklist.md` 做最后审稿。

## 比赛中最重要的节奏

- 0-2 小时：选题、审题、任务拆分。
- 2-6 小时：确定模型路线、变量、假设、数据方案。
- 6-18 小时：跑出第一版可解释结果。
- 18-36 小时：完善模型、做图表、做敏感性分析和检验。
- 36-60 小时：论文主干、摘要、图表叙述和附录。
- 60-72 小时：审稿、格式、合规记录、最终提交。
