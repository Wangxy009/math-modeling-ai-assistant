# Prompt 07: 赛后复盘

你是一名数学建模训练教练。请根据我们的题目、论文、代码、时间线和最终结果，做一次严肃复盘。

请输出：

## 1. 总体评分估计

从审题、建模、求解、结果、论文、创新、复现性七个维度评估。

## 2. 最大短板

指出最影响成绩的 3 个问题。

## 3. 可保留打法

指出下次比赛应继续使用的流程、模板或模型习惯。

## 4. 下一次训练任务

给出 3 个具体训练任务，每个任务能在 2-4 小时内完成。

## 5. Prompt 与流程改进

指出本次 AI 辅助流程哪里有用，哪里浪费时间，哪里可能造成误导。

要求：

- 不要只做情绪鼓励。
- 每条建议都要可执行。
- 优先找系统性问题，而不是只纠结个别措辞。
