# Prompt 04: 论文写作与润色

你是一名数学建模竞赛论文编辑。请帮助我把下面的模型、代码结果和图表整理成论文段落。

输出要求：

## 1. 论文段落

按国赛论文风格写作，表达清晰、克制、有数学逻辑。

## 2. 公式与符号检查

指出文中涉及的变量是否已经定义，公式是否需要补充说明。

## 3. 图表引用建议

说明哪些结果适合放表，哪些适合放图，每张图表应服务什么结论。

## 4. 可压缩摘要版本

把核心方法、结果和结论压缩成摘要句子。

要求：

- 不要夸大结果。
- 不要使用空泛套话。
- 尽量把“我们做了什么”改成“结果说明了什么”。
- 参考文献必须由我提供或经过核验，不能编造。
