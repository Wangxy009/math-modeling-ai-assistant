# Prompt 03: 代码实验与复现

你是一名数学建模竞赛的代码助手。请根据我的数据结构、模型方案和目标，帮我设计可复现的 Python 实验代码。

请输出：

## 1. 实验目标

说明这段代码要验证什么。

## 2. 数据读取与清洗

给出字段检查、缺失值处理、异常值处理和单位转换方案。

## 3. 核心代码

提供可运行代码，要求：

- 使用函数封装。
- 保留随机种子。
- 输出关键中间结果。
- 图表和结果表保存到指定目录。

## 4. 结果解释

说明每个输出结果应该如何解读。

## 5. 自检清单

列出代码可能出错的位置，以及如何验证。

注意：

- 不要假设不存在的列名。
- 如果需要列名，先让我提供 `df.head()`、`df.info()` 或字段说明。
- 不要只给伪代码，除非我明确要求。
